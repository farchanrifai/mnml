## Existing good foundations retained

Background pages are lazy (`Tab.swift:255-265`), other-space rows hold sleeping tabs (`Browser.swift:3141-3168`), MRU preview cache is bounded by ten IDs (`TabSwitcher.swift:58-64`), absent favicon lookups are negatively cached (`Icons.swift:83-93`), downloaded-icon decoding already occurs off-main (`Icons.swift:190-246`), bookmark membership is a cached Set (`Bookmarks.swift:38-51`), background writes preserve latest ordering (`Store.swift:179-221`), ordinary session/history saves are coalesced (`Browser.swift:2307-2315`, `History.swift:538-553`), and sleep/archive timers already have tolerance (`Sleep.swift:44`, `Archive.swift:115`). These should be profiled before replacement.

## Release measurement recipe

Use a new isolated `MNML_PROBE` world with `MNML_MEASURE=1` and release preview. Keep external pages/static content identical in each baseline/fix run, and record the app main process separately from content-process activity. Capture launch, 30 seconds idle, 200-tab restore, command-bar typing, open/close/move window churn, history/bookmark panel search, and parallel download row updates. Record main-thread CPU/hangs, first usable frame, interaction latency median/p95, animation hitches, live allocations, timer wakeups, and disk writes. Do not claim a numeric improvement until the baseline and candidate are measured under the same fixtures and app/SDK configuration. Native UI/visual animation acceptance belongs to the parent/other audit agents.
